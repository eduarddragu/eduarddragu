# CLAUDE.md

GitHub profile README. `README.md` shows SVG cards from `assets/`, each in a light and a dark version.

## Working here

- The SVGs are generated: never edit `assets/` by hand. Change `scripts/build.mjs` (copy, palette, layout), then run `node scripts/build.mjs` and commit the regenerated files with it.
- The palette and type follow eduarddragu.dev. Keep them in sync with the site rather than tuning them here.
- When copy changes in an SVG, update the matching `alt` text in `README.md`.
- This repo is public: no personal data beyond what the profile already shows.
- Plain English, no em dashes. Don't commit or push unless asked.
